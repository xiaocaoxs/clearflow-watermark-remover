# 智能去水印平台 · 技术方案文档

> 版本：v1.0 ｜ 日期：2026-10-25 ｜ 定位：支持图片/视频的多平台水印检测与去除 Web 应用

---

## 1. 项目概述

### 1.1 产品目标
构建一个 Web 端去水印工具，用户通过**本地文件上传**或**分享链接**（小红书/抖音/TikTok）导入素材，系统自动检测并去除水印，支持**先预览对比效果、再确认保存**的交互闭环。

### 1.2 核心能力
| 能力 | 说明 |
|------|------|
| 素材导入 | 本地拖拽/点击上传；粘贴分享短链自动解析无水印源 |
| 水印检测 | 自动识别 TikTok / 抖音 / 小红书 logo 及文字水印，输出精确区域 |
| 水印去除 | 图片：OpenCV inpaint 修复；视频：FFmpeg delogo 滤镜（支持移动水印分时段处理） |
| 效果预览 | 前后对比视图（滑动对比/并列对比），满意后再保存 |
| 保存 | 浏览器下载；移动端通过 Web Share API 唤起"保存到相册" |

### 1.3 水印特征分析（实测样本）
| 平台 | 水印构成 | 位置特征 |
|------|----------|----------|
| TikTok | 音符 logo + "@用户名" + "TikTok"字样 | 左上角出现，随时间**移动到右上角** |
| 抖音 | 音符 logo + "抖音号：xxx" | 左上角固定 |
| 抖音(下载版) | 搜索图标 + 关键词（如"晨光电台"） | 底部固定 |
| 小红书 | "小红书"字样 / "记录我的生活" + 用户名 | 多为右上或底部 |

**关键技术挑战**：TikTok 水印随时间移动 → 需要**分时段检测 + 分段 delogo**。

### 2.1 技术选型理由

**前端**
| 技术 | 用途 | 选型理由 |
|------|------|----------|
| React 18 + TypeScript | 框架 | 用户指定；类型安全利于中大型项目 |
| Vite | 构建 | 秒级 HMR，生态标准 |
| TailwindCSS 3 | 样式 | 用户指定；原子化快速开发 |
| shadcn/ui (Radix) | UI库 | 可定制、无锁定、品质高、与 Tailwind 深度集成 |
| framer-motion | 动效 | Tab 切换/进度/结果展示的流畅动画 |
| react-dropzone | 上传 | 拖拽上传标准方案 |
| axios | 请求 | 拦截器统一处理 |
| lucide-react | 图标 | 与 shadcn 配套 |

**后端**
| 技术 | 用途 | 选型理由 |
|------|------|----------|
| Python 3.11 + FastAPI | API 服务 | OpenCV 生态最成熟；自动生成 OpenAPI 文档；异步高性能 |
| OpenCV (cv2) | 检测+图片修复 | 模板匹配/inpaint 开箱即用 |
| FFmpeg | 视频处理 | delogo 滤镜工业级稳定；逐帧提取用于检测 |
| httpx | 链接解析 | 异步 HTTP，模拟 UA 抓取分享页 |
| Uvicorn | 服务器 | ASGI 标配 |

**为什么后端选 Python 而非 Node**：水印检测是计算机视觉问题，OpenCV 的 Python API 完整度远超 opencv4nodejs（后者已停止维护、编译困难）；FFmpeg 通过 subprocess 调用与语言无关；后续若升级深度学习修复（LaMa/ProPainter），Python 生态无缝衔接。

## 3. 核心算法设计

### 3.1 水印检测算法（ Detector ）

采用**"候选区域分析 + 模板确认"两阶段策略**，纯规则、零模型依赖，稳定且可解释：

```
输入帧 (BGR)
   │
   ▼
[阶段1: 候选区域生成]
   ├─ 定义平台先验候选框: 左上/右上/右下/底部条带
   │
   ▼
[阶段2: 逐候选区域验证]
   ├─ 转灰度 → 自适应阈值二值化(强调白色文字/logo)
   ├─ 形态学膨胀连接笔画
   ├─ 轮廓提取 + 外接矩形合并
   ├─ 过滤: 面积/宽高比/密度 噪声过滤
   ├─ (可选) cv2.matchTemplate 与内置平台logo模板匹配确认平台类型
   ▼
输出: 水印区域列表 [(x, y, w, h, confidence), ...]
```

**关键参数**
- 二值化阈值：THRESH_BINARY + OTSU 自适应
- 文字区域特征：白色前景 + 高对比度 + 紧凑轮廓
- 面积过滤：`w*h ∈ [0.0005, 0.25] × 帧面积`
- 纵横比过滤：`1.5 ≤ w/h ≤ 30`（文字多为横向长条）

**视频时序策略（处理移动水印）**
1. 按 `t = 0.5s` 步长均匀采样 N 帧（默认时长≤60s 采 24 帧）
2. 对每帧独立检测水印区域
3. 聚类：将各时间点检测到的区域按位置分组（IoU>0.3 或中心距离阈值归并）
4. 每组生成"位置-时间"轨迹 → TikTok 水印前半段在左上、后半段在右上 → 拆分为两个**时间段×区域**组合

### 3.2 水印去除算法（ Remover ）

**图片：cv2.inpaint（Telea 算法）**
```
mask = 检测区域膨胀(3px, 保证边缘干净)
result = cv2.inpaint(image, mask, inpaintRadius=4, flags=INPAINT_TELEA)
```
Telea 基于快速行进法，从区域边界向内传播等照度线，对白色半透明水印修复自然。若水印较大且背景复杂，可升级 NS 算法或深度模型。

**视频：FFmpeg delogo 滤镜链**
```bash
ffmpeg -i in.mp4 -vf \
  "delogo=x=..:y=..:w=..:h=..:show=0, delogo=..." \
  -c:a copy out.mp4
```
- delogo 对矩形区域做邻域插值淡化，对 logo/文字类水印效果可靠
- 移动水印：同一区域不同时段用 `delogo=...:enable='between(t,0,4.5)'` 控制
- 音频流直接 copy，避免二次压缩
- 视频流：H.264 CRF 18 保持画质

**质量兜底**：delogo 后若区域边缘有残留，可叠加轻微 `boxblur` 于同一区域。

### 3.3 链接解析（ Link Resolver ）

```
用户粘贴 https://xhslink.cn/xxx
   │ httpx (移动端UA, follow_redirects)
   ▼
解析重定向得到最终页面 / 或直接得到视频直链
   │
   ├─ 小红书: 提取页面 __INITIAL_STATE__ JSON → note.video.mediaStream → masterUrl
   ├─ 抖音: iesdouyin 分享接口 → video.play_addr
   └─ TikTok: 页面 JSON-LD / __UNIVERSAL_DATA → video.downloadAddr
   ▼
后端代理下载无水印源文件 → 进入处理管线
```

> 说明：平台反爬策略持续变化，解析器做成**插件式策略模式**，单平台失效不影响整体；请求统一带移动端 UA 与必要头。小红书直链需要 `Referer` 校验时由后端代理下载。

## 4. API 设计

| Method | Path | 说明 |
|--------|------|------|
| POST | `/api/upload` | 上传本地文件（multipart），返回 taskId |
| POST | `/api/parse-link` | 传分享链接，返回解析结果 + taskId |
| POST | `/api/process` | 传 taskId，执行检测+去除，返回结果元数据 |
| GET  | `/api/result/{taskId}/preview` | 处理后文件流（预览用，带 Range 支持视频拖动） |
| GET  | `/api/result/{taskId}/download` | 下载成品 |
| GET  | `/api/task/{taskId}` | 任务状态轮询（检测区域、进度） |
| GET  | `/api/health` | 健康检查 |

**任务生命周期**：`uploaded → detecting → processing → done / failed`

## 5. 前端页面设计

### 5.1 页面流
```
[Tab: 图片 | 视频]
   ↓ 选择导入方式
[① 本地上传区(拖拽/点击)  |  ② 链接输入框 + 解析按钮]
   ↓ 后端处理（进度反馈动画）
[检测结果页: 原图/视频 ↑↓ 左右滑块对比]
   ↓ 用户确认
[保存: 下载按钮 / 保存到相册(Web Share API)]
```

### 5.2 组件树
```
App
├── Header (logo + 标题 + GitHub 风格导航)
├── Hero (渐变标题 + 副标题)
├── MediaTabs (图片/视频 Tab, framer-motion 切换动画)
│   └── ImportPanel
│       ├── DropZone (react-dropzone)
│       └── LinkInput (粘贴链接 + 平台自动识别图标)
├── ProcessingView (进度 + 检测到的水印区域可视化)
├── ResultView
│   ├── CompareSlider (前后滑动对比)
│   ├── VideoCompare (双播放器同步对比)
│   └── SaveActions (下载 / 保存到相册)
└── Footer
```

### 5.3 交互细节
- 检测到的水印区域用**半透明红框**叠加在原图上展示，增强"AI 在工作"的感知
- 视频预览提供"处理前/处理后"同步播放对比
- 保存到相册：`navigator.canShare({files})` 探测 → 移动端调起系统分享面板（可存相册/相薄）；桌面端降级为下载

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| TikTok 水印移动导致单区域 delogo 失效 | 分时段检测：每个采样时刻独立定位，生成带 enable 时间条件的滤镜 |
| 小红书反爬升级 | 策略插件化；必要时提示用户改用本地下载文件上传 |
| delogo 边缘残留 | mask 膨胀 + 局部轻微模糊；后续可引入 LaMa 深度修复 |
| 大视频处理耗时 | 采样检测而非全帧检测；delogo 为单遍滤镜，速度可控；任务异步化 |
| 版权合规 | 仅处理用户自有素材，页面添加免责声明 |
